Проект: Простая веб-страница (HTML + CSS)

Данный проект представляет собой минимальный шаблон веб-страницы, включающий основной HTML-файл и файл стилей CSS. В примере создаётся пустой элемент <header> с фиксированной высотой и чёрным фоном.

Содержимое проекта

index.html
style.css

Описание файлов

index.html
Основная структура страницы и подключение файла стилей.

style.css
Стили для страницы и шапки.
